# 오리온 리디자인

이준화 포트폴리오를 위한 오리온 리디자인 정적 사이트입니다. HTML, CSS, JavaScript로 구성되어 있으며 별도의 설치나 빌드가 필요하지 않습니다.

## GitHub Pages 배포

1. GitHub에 새 저장소를 만듭니다.
2. 이 폴더 안의 모든 파일과 `assets` 폴더를 저장소의 최상위에 올립니다. 숨김 파일인 `.nojekyll`도 포함합니다.
3. 저장소의 **Settings → Pages**에서 **Deploy from a branch**, `main` 브랜치, `/(root)`를 선택하고 저장합니다.

`index.html`은 저장소 루트에서 열리도록 구성되어 있습니다. 기존 포트폴리오 프로젝트의 `orion` 폴더는 별도로 유지됩니다.

로고와 제품 이미지는 포트폴리오 시안에 사용된 자료입니다. 글꼴 출처는 `assets/fonts/SOURCES.md`를 참고하세요.
